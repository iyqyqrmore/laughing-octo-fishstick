## Explicitly preserved

Byte-identical to the base: ManualExecution, LimitOrderServices, manual/native trade parser, fee-unit normalization, live beta/limits/grants and original LiveBroker/LiveLedger, TrialStore/TrialClock (including Windows closure correction), FIFO/tax/inventory/verified-fill/state/data-transfer/backup/key/single-instance libraries, and approved PNG/ICO assets. Canonical financial and security tests remain. The fresh-setup helper changes current display/producer labels and temporary prefix only; initialization/empty-destination/confirmation/security behavior is unchanged. Historical module/schema/marker names remain compatibility identifiers.

No private database, financial journal, original shadow record, tax/FIFO data, key, backup, receipt or favorite file is a deletion candidate. Old `research_data/resumable_trial`, `assumed_fill_sandbox` and `opportunity_shadow` are opened only by the explicit read-only viewer; it verifies checkpoint digests, closes resources and never creates a controller or increments clocks. New controller state and hourly-reference cache are separate. Actual manual pending-order safeguards still read their established journals.

Source-only `__pycache__` may be reported/cleaned by STORAGE_REPORT; financial/research storage is never removed. Source ZIP uses an explicit allowlist and excludes runtime databases, credentials, caches and account artifacts. Archive documents retain original commit/version evidence with a v1.05 archive banner. Native Windows, connected-account and predictive/fill calibration are not inferred from this map.
